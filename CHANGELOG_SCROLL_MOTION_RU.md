# KOKTUR Web 1.2.4 — Scroll Motion

- Добавлен плавный reveal секций и карточек при прокрутке вниз.
- CSS 3D-модель KOKTUR плавно меняет позицию, наклон, масштаб и оттенок во время прокрутки первого экрана.
- Используется пассивный scroll listener с ограничением обновления одним requestAnimationFrame на кадр.
- Обновлён service worker cache version, чтобы посетители получили актуальные стили и скрипт.
- Уменьшена нагрузка на низкопроизводительных устройствах; поддерживается системная настройка reduced motion.
- Основной интерфейс чата, история и формы входа/регистрации не переделывались.
